## 2. Palette Balance Ratios (`DECIDED`)

- **85% Neutral Field:** Generous Warm Ivory whitespace establishes the luxury publication tone.
- **10% Ink & Structure:** Deep Black and Graphite typography, rules, and vector geometry.
- **5% Bronze Accent:** Restricted to active navigation, primary conversion CTA, and coordinate micro-accents.
- **Silver / Chrome Exclusion:** Silver is excluded from the core UI system; permitted only for subtle media captures.
