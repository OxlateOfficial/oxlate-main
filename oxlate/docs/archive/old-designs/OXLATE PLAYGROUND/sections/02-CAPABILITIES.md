# 02 — CAPABILITIES SECTION — OXLATE V1

Version: 3.0  
Status: ACTIVE STRATEGIC AUTHORITY  
Last Updated: 2026-09-10

---

## 1. Purpose
Defines the concrete spectrum of engineering and design services Oxlate provides, establishing technical capability without overwhelming the visitor with a desperate list of 14 generic agency cards.

---

## 2. Intended User Feeling
Clarity, competence, and focus. The visitor should recognize:
> *"They don't try to be everything to everyone; they are focused experts in modern web and mobile product engineering."*

---

## 3. Information Hierarchy
1. **Section Tag:** Monospace indicator `02 // CAPABILITIES`.
2. **Section Headline (H2):** "Built for real workflows."
3. **Capability Pillars:**
   - *Pillar 1:* Web & Web Applications (Websites, web apps, portals in Next.js / React).
   - *Pillar 2:* Mobile Applications (iOS, Android, React Native mobile products).
   - *Pillar 3:* Custom Software & Internal Tools (Tailored operational software, dashboards, business systems).
4. **Supporting Tech Stack Metadata:** Minimal monospace technology tags (React, Next.js, React Native, TypeScript, Node.js, PostgreSQL).

---

## 4. Visual Direction (`RECOMMENDATION`)
- **Grid Layout:** 3 architectural columns on desktop (`≥ 1024px`), stacking into a single column on mobile (`< 768px`).
- **Surface Materiality:** Parchment card fill (`#FAF8F5`), Pale Stone border (`#D9D4CC`), sharp `2px–6px` corner radii.
- **Threshold Transition Bridge (`RECOMMENDATION`):** Position the Diagonal Service Band from `HeroRoughIdea.png` as a dynamic datum beam at the top boundary of Section 02, introducing the disciplines as the user scrolls into the section.

## 6. Animation Intention
- **Section Entrance:** Top hairline datum draws left-to-right as user enters viewport.
- **Card Reveal:** Staggered 10px subtle translateY fade-up (150ms per card).
- **Hover Micro-interaction:** Subtle border contrast elevation (`#D9D4CC` to `#111111` or `#A87445`); zero bouncy scaling.
