## 1. Core UI Component Catalog (`DECIDED`)

Only components that genuinely belong to the Oxlate architectural visual language are defined here:

### 1. Primary Bronze Button (`CTA`)
- **Visual:** Solid Bronze fill (`#A87445`), Pure White text (`#FFFFFF`), sharp tectonic radius (`2px–4px`), font-mono uppercase tracking.
- **Behavior:** Darkens to Warm Bronze (`#B98250`) on hover; -1px vertical lift over 150ms; zero spring bounce.
- **Usage:** Primary conversion triggers ("Contact", "Start a conversation").

### 2. Secondary Link / Action
- **Visual:** Transparent background, Pale Stone hairline border (`#D9D4CC`), Deep Black text (`#111111`), sharp tectonic radius.
- **Behavior:** Border shifts to Deep Black (`#111111`) or Bronze (`#A87445`) on hover.

### 3. Fixed Top Architectural Header (`Navbar`)
- **Visual:** Fixed top bar, Warm Ivory backdrop blur (`bg-background/90 backdrop-blur-md`), bottom Pale Stone hairline border.
- **Left:** Authentic vector mark (`Oxlate_logoX_blk.svg`).
- **Right:** Essential section links (`Capabilities`, `Work`, `Approach`, `About`, `Contact`) and the primary bronze CTA button.

### 4. Side Navigation Dial & Mobile Ticker (`DECIDED` on Desktop, `RECOMMENDATION` on Mobile)
- **Desktop (`≥ 1024px`):** Vertical monospace index in the right margin (`01 INTRO` to `06 CONTACT`) with active state highlighted in Deep Black and a bronze focal marker.
- **Mobile (`< 768px`):** Minimal floating status pill or top breadcrumb ticker (`01 / 06 • INTRO`).

### 5. Structural Content Frame / Card Shell
- **Visual:** Parchment fill (`#FAF8F5`), Pale Stone border (`#D9D4CC`), sharp `2px–6px` corner radii, generous internal padding, zero fuzzy drop shadows.

### 6. Transparency Disclosure Badge (`Badge`)
- **Visual:** Small, crisp metadata badge rendered on project cards.
- **Mandatory Labels:** Must render `Independent Project` or `Founding Developer's Work`.
