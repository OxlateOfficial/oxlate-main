---

## 1. Universal Section Anatomy (`DECIDED`)

Every homepage section adheres to a consistent structural anatomy:

1. **Semantic Anchor:** Unique HTML `id` (`#intro`, `#capabilities`, `#work`, `#approach`, `#about`, `#contact`).
2. **Datum Scoring Border:** Top `1px` hairline border in Pale Stone (`#D9D4CC`) dividing sections cleanly.
3. **Chapter Coordinate:** Left-aligned monospace chapter tag (`01 // INTRO`, `02 // CAPABILITIES`, etc.).
4. **Semantic Heading:** Clear, disciplined H2 heading in Deep Black (`#111111`).
5. **Section Lead / Context:** Concise 1–2 sentence explanatory copy in Neutral Slate (`#6C6B66`).
6. **Architectural Content Area:** Fluid layout grid (columns, cards, or project showcase frames).

---

## 2. Standard 8-Point Section Specification Standard (`DECIDED`)

Every section document inside `sections/` must explicitly define these 8 dimensions:

1. **Purpose:** Why this section exists in the user journey.
2. **Intended User Feeling:** The psychological and emotional response.
3. **Information Hierarchy:** Ordering of message weight from primary to supporting.
4. **Visual Direction:** Materiality, spatial layout possibilities, framing, and alignment.
5. **Possible Elements:** Catalog of primitives, UI elements, and motifs that can compose this section.
6. **Animation Intention:** Scroll progression, entry reveals, and micro-interactions.
7. **SEO Requirements:** Semantic HTML tags, crawlability, and schema alignments.
8. **Open Creative Questions:** Undecided items requiring owner approval or creative exploration.
