## Decision on 3D Models
- **Status in V1:** DEFERRED / EXCLUDED FROM CORE FLOW.
- **Rationale:** As documented in `ThinkLikeThis.md` and `Visual and Theme.md`, heavy 3D WebGL models (e.g. `laptop.glb`, `macbook_ultra_concept.glb`) introduce high JavaScript execution overhead, potential mobile jank, and distract from the primary value proposition.
- **Rule for V1:** The website relies on clean vector geometry, typography, and high-resolution 2D architectural mockups. No interactive 3D canvas is required for the V1 release.
